# Code of Conduct

MADVA contributors are expected to be respectful, constructive, and precise. Participate in good faith, welcome different backgrounds, and focus criticism on designs and code rather than people.

Harassment, discrimination, threats, doxxing, deliberate exposure of private information, and malicious disruption are not acceptable. Maintainers may remove content or restrict participation when behavior violates these expectations.

Report conduct concerns privately to the repository owner through GitHub. Do not include unrelated secrets or customer data in a report.
